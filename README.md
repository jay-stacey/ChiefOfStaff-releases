# Chief of Staff releases

This repository holds only the Windows installers and the update file (`latest.json`) for Chief of Staff.
The source code is private.

- Download the newest setup file from [Releases](https://github.com/jay-stacey/ChiefOfStaff-releases/releases/latest).
- Installed copies check `releases/latest/download/latest.json` and install a newer version only after the user says yes.
- Every setup file is signed with the Chief of Staff updater key. The app refuses a file whose signature does not match.
